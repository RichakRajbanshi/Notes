AI STUDY BUDDY SETUP (Vercel)
1. Get an API key from https://aistudio.google.com/apikey
2. Vercel > your project > Settings > Environment Variables
   Name: GEMINI_API_KEY   Value: (your key)
3. Redeploy. Never put the key in index.html or GitHub.
Optional: add MODEL (default gemini-2.5-flash) to change the AI model.
